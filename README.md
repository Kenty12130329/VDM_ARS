# VDM-PP Random Search Tool (Java_RandomSearch)

本ツールは、SMTソルバー（Z3）を一切使用せず、VDMJ（VDM-PPインタプリタ）を直接制御してランダム探索を行うJavaプログラムです。
モデルの不変条件（`inv`）違反を検出し、その再現トレースを出力する対照実験用ツールとして設計されています。

---

## フォルダ構成

* **`src/main/java/com/fujitsu/robot/`**: ソースコード
  * `ArsMain.java`: ツールのエントリーポイント。引数の解析やCSVの設定を行います。
  * `ArsExplorer.java`: ランダム探索のメインループ。ランダム引数の生成、不変条件の論理評価を行います。
  * `ArsVDMController.java`: VDMJプロセスとの入出力同期、変数ダンプのパースを担当します。
  * `StringValue.java`: パース用ユーティリティクラス。
* **`jar/`**: 依存ライブラリ
  * `vdmj-4.6.0.jar`: VDM-PPインタプリタ。
* **`resources/`**: VDM-PPモデルファイル（`.vdmpp`）および遷移定義ファイル（`.csv`）
* **`build.bat`**: コンパイル用バッチスクリプト
* **`run_ars.bat`**: ビルドおよび探索実行用バッチスクリプト

---

## 事前準備・動作環境

* **Java Development Kit (JDK 8以上)** がシステムにインストールされ、`javac` および `java` コマンドにパスが通っている必要があります。

---

## ビルドと実行方法

### 1. ビルド手順
以下を実行してコンパイルします。
```bash
build.bat
```
※クラスファイルは `bin/` ディレクトリ配下に自動出力されます。

### 2. 実行手順
`run_ars.bat` を使用してランダム探索を実行します。
```bash
run_ars.bat <モデルファイルのパス> [探索の最大深さ] [最大試行回数]
```
* **第1引数**: 検証対象の `.vdmpp` ファイルのパス（必須）
* **第2引数**: 各試行（Run）における遷移の最大ステップ数（デフォルト: `10`）
* **第3引数**: 最大試行回数（デフォルト: `1000`）

---

## 実行例と検証シナリオ

### ① 図書館システム（複数貸出バグの検出）
学生が上限（1冊）を超えて本を借りてしまう不変条件違反のバグを検出するシナリオ。
```bash
run_ars.bat resources/book_f1.vdmpp 10 1000
```
* **期待される結果**: 数Run以内で不変条件違反（`violation`）を検出し、探索が正常終了します。

### ② コンビニ支払システム（44桁正常系／二重支払バグ検出）
JIS X 0502準拠チェックデジットを用いたコンビニ収納代行システムの検証。

* **正常系モデルの完走確認**:
  ```bash
  run_ars.bat resources/ConveniPayment44.vdmpp 10 100
  ```
  ※不変条件を違反することなく指定回数完走します。

* **二重支払バグ（不変条件違反）の検出**:
  ```bash
  run_ars.bat resources/ConveniPayment44_bug.vdmpp 10 1000
  ```
  ※二重支払による不変条件違反を数Run以内で検出します。

### ③ 外部引数チェックデジット制約による探索限界の実証（ストップ現象の証明）
外部からCD付き引数を受け取るモデルに対し、ソルバーなしのランダム探索がどれほど無力かを証明する対照実験。
```bash
run_ars.bat resources/ConveniPayment.vdmpp 10 100
```
* **期待される結果**: 100%すべての試行において、1ステップ目の `pay(...)` の事前条件チェック（CDおよびDB照合）に失敗し、**`[Dead End]` となって探索が即座にストップ**します。
* ソルバー（Z3など）を用いない場合、約700億分の1という天文学的な低確率をランダムで引き当てる必要があり、探索がストップする事実を直接証明できます。

## 📄 出力されるログファイル

探索実行後、本ディレクトリ直下に以下のファイルが出力されます。

1. **`found_trace.txt`**
   * 不変条件違反を検出した際に出力される、初期状態から違反発生までの遷移パス（トレース）。
2. **`transition_log.csv`**
   * 各Runにおける操作（メソッド実行）の履歴ログ。デッドエンドで終了した箇所も記録されます。
3. **`variable_history.csv`**
   * 探索中に遷移した状態変数の値の推移データ。
4. **`statistics_summary.txt`**
   * 実行時間、総ステップ数、違反検出有無などの統計要約情報。
